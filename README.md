# 🏦 Russian Standard Bank — UI/UX Educational Frontend Clone

[🔗 Открыть интерактивную демо-версию проекта](https://react-rsb.vercel.app/)

> ⚠️ **Дисклеймер (Disclaimer):** Данный проект является исключительно учебной работой (Educational Clone), создан в целях комплексного изучения фронтенд-разработки, адаптивной верстки и интеграции с гео- и финансовыми сервисами. Проект не является коммерческим продуктом и не собирает персональные данные.

Проект представляет собой интерактивную веб-страницу (лендинг) банка, разработанную на базе React и JSS (CSS-in-JS). 

* **Авторство дизайна:** Визуальный интерфейс спроектирован в рамках дисциплины «UI/UX дизайн (Паттерны проектирования дизайна и исследование пользовательского опыта)» университета **Синергия**. Оригинальный дизайн-концепт детально разобран и предоставлен преподавателем курса, а затем дополнен в учебных целях для отработки навыков работы в Figma.
* **Авторство разработки:** Самостоятельная техническая реализация архитектуры, логики, стейт-менеджмента и фронтенд-части с нуля.

---

## 🛠 Стек технологий и архитектура
* **Frontend-библиотека:** React.js (функциональные компоненты, кастомные хуки).
* **Стилизация:** JSS (CSS-in-JS) для изолированной и масштабируемой стилизации компонентов.
* **Сборщик проекта:** Vite (обеспечивает мгновенный Hot Module Replacement).
* **Интеграции и API:** 
  * API Яндекс.Карт (модули `suggest`, `geocode`, `geolocation`).
  * API Центрального Банка РФ (ежедневные официальные котировки валют).

Приложение спроектировано компонентно и разделено на 5 ключевых функциональных блоков.

## 📦 Детальный разбор компонентов

### 1. Header (Многоуровневая навигация)
Сложная навигационная панель, построенная по принципу строгой декомпозиции (разделена на подкомпоненты `LevelOne`, `LevelTwo`, `LevelThree`) с централизованным управлением состоянием.

* **3-х уровневая архитектура меню:** Динамическое управление шторками и выпадающими списками контролируется единым стейтом `activeMenu` на уровне родительского хедера. Клик по вкладкам второго уровня (например, категории продуктов) плавно выдвигает детальные подкатегории третьего уровня.
* **Синхронизация гео-данных:** Инициализация стейта `selectedCity` происходит через утилиту `getSelectedCity()`. Хук `useEffect` подписывается на событие автоматического определения города от Яндекс.Карт через модуль `yandexCityDetected`. Выбор нового региона в хедере синхронизирует глобальное состояние и автоматически меняет центровку интерактивной карты ниже на странице.
* **Плавный скролл:** Ссылка «Офисы и банкоматы» изолирована в утилиту `scrollToId("map")`, обеспечивая аккуратный переход к целевому контейнеру.
* **UI-заглушки:** Элементы «О банке», «RU», «Поиск» и «Интернет-банк» не функциональны и служат для сохранения визуальной целостности интерфейса.

### 2. PromoBlock (Главный баннер и авторизация)
Маркетинговый блок (Hero Section), совмещающий в себе паттерн привлечения внимания и точку входа в пользовательский интерфейс.

* **Двухколоночная структура (Split-screen):** Четкое визуальное разделение фокуса пользователя. Левая часть генерирует лиды (акцент на акцию «Кэшбек 10%»), правая — обеспечивает быстрый доступ в личный кабинет для действующих клиентов.

### 3. CatalogSection (Динамический каталог и Квиз-интеграция)
Интерактивная витрина банковских продуктов с гибким переключением категорий и встроенным геймифицированным элементом.

* **Гибридный стейт-менеджмент табов:** Реализована автоматическая ротация категорий («Личные финансы», «Молодежи», «Премиум» и др.) с интервалом в 5 секунд через `useEffect`. 
* **Умная остановка автоплея:** При ручном взаимодействии (клик пользователя по любому табу) таймер автоматически сбрасывается (`setIsAutoPlay(false)`), фиксируя фокус на выбранном контенте.
* **Data Mapping:** Контент карточек вынесен в изолированные структуры данных (`PERSONAL_DATA`, `YOUTH_DATA`) и мапится через конфигурационный объект `dataMap` по текущему стейту `activeTab`, исключая тяжелые конструкции `switch-case`.
* **Нативный перезапуск анимаций (`key` trick):** На контейнер сетки повешен динамический ключ `key={activeTab}`. При смене категории React полностью пересоздает DOM-ноду, что автоматически перезапускает CSS-анимацию плавного появления (`fadeIn`), делая переход визуально мягким без сторонних JS-библиотек.
* **Геймификация:** Статичная карточка квиза («Не знаете какой продукт Вам подойдет?») использует аватар-стэк и динамический счетчик реального времени («158+ проходят прямо сейчас») для подталкивания пользователя к целевому действию.

### 4. MapBlock (Интерактивная карта с геосервисами)
Сложный гео-компонент, реализующий автоматическое центрирование, поиск адресов и динамическую фильтрацию инфраструктуры.

* **Архитектурное разделение (Custom Hooks):** Вся императивная работа с инстансом карты, подпиской на события `onLoad` и инициализацией поискового саджеста (`suggest,geocode,geolocation`) изолирована в кастомный хук `useMapSuggest()`.
* **Автоматическое определение локации:** При первичном рендеринге приложение запрашивает геопозицию пользователя и центрирует карту на его координатах, устанавливая кастомную зеленую метку.
* **Умный поиск с автодополнением (Suggest API):** В инпут ввода адреса встроен механизм поисковых подсказок от Яндекса. При выборе адреса из выпадающего списка карта автоматически выполняет геокодирование и плавно перемещает фокус (`map.panTo()`).
* **Динамическая фильтрация:** Переключатель «Офисы / Банкоматы» мгновенно перестраивает массив гео-меток на карте на основе метода `.filter()`, изменяя их визуальный пресет (синие метки для отделений, красные с иконкой валюты — для банкоматов). Чекбоксы фильтров услуг в текущей версии являются декоративными.

### 5. Footer (Информационный подвал и курсы валют)
Заключительный информационный блок, воссоздающий структуру и юридические стандарты реального банковского интерфейса с интеграцией динамических данных регулятора.

* **Интеграция с API Центрального Банка РФ:** Актуальные котировки валют загружаются напрямую с серверов ЦБ РФ через интеграционный скрипт `cbr-xml-daily.ru`, подключенный в `index.html`. Данные инициализируют глобальный объект обмена `window.fx`.
* **Асинхронный Polling (Хук `useExchangeRates`):** Внутри хука реализован рекурсивный цикл ожидания (`setTimeout` на 100мс). Он проверяет доступность объекта `window.fx` в глобальной области видимости, предотвращая падение React-приложения при первичном рендеринге до того, как скрипт ЦБ успеет загрузиться. Хук производит нативный пересчет инвертированных биржевых котировок в прямое рублевое соотношение.
* **Алгоритм симуляции коммерческого спреда:** Так как API отдает чистый официальный курс ЦБ, внутри хука алгоритмически моделируется реальное экономическое поведение коммерческого банка. Система рассчитывает маржинальность в реальном времени, вычитая фиксированный спред на покупку (`-0.5 руб.`) и добавляя на продажу (`+2.5 руб.`) с округлением до двух знаков через `.toFixed(2)`.
* **Правовой комплаенс (Legal UX):** Реализованы обязательные для финтех-продуктов элементы — плашка предупреждения о сборе файлов `cookie`, официальный блок АСВ (Агентства по страхованию вкладов), а также измененный текст копирайта, указывающий на учебный статус проекта.

### 6. Компонент: AuthModal (Многошаговая OTP-авторизация)
Высокотехнологичный компонент формы входа в интернет-банк, спроектированный в виде стейт-машины (Wizard Pattern) и интегрированный с продвинутыми инструментами валидации и сетевого взаимодействия.

#### 🌟 Функционал и UX-паттерны:
* **Многошаговый интерфейс (Multi-step Form):** Процесс разделен на два изолированных подкомпонента (`StepOne` и `StepTwo`). Вместо избыточной одновременной формы логин/пароль, интерфейс сначала запрашивает телефон, верифицирует его на сервере, и только потом плавно переключает пользователя на шаг ввода пароля.
* **Декларативный сброс жизненного цикла (Key Reset Pattern):** Полный сброс полей и возврат к первому шагу реализован без использования эффектов (`useEffect`). В родительском компоненте на модалку повешен пропс `key={isAuthOpen}`. При закрытии окна React полностью размонтирует инстанс, бесследно зачищая конфиденциальные данные из оперативной памяти браузера.
* **Интеллектуальная валидация (onTouched Mode):** Форма не раздражает пользователя агрессивными предупреждениями на каждую вводимую букву. Ошибки подсвечиваются только в том случае, если поле было затронуто, но оставлено недописанным. Кнопка «Далее» динамически активируется на глазах ровно в тот момент, когда введены все 11 цифр.

#### ⚙️ Техническая реализация:**
* **Производительный сбор данных (React Hook Form + getValues):** Использование метода `getValues` вместо `watch` позволило полностью изолировать ввод текста от рендеринга. Форма рендерится исключительно при смене шагов, не нагружая процессор ререндерами при печати букв.
* **Экосистема валидации (Yup & yup-phone-lite):** Валидация вынесена в отдельный слой `validationSchema.js`. Проверка корректности номера телефона делегирована специализированному плагину `yup-phone-lite`, использующему международные стандарты кодов связи (ISO RU).
