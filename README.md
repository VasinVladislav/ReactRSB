# 🏦 Russian Standard Bank — UI/UX Educational Frontend Clone

[🔗 Открыть интерактивную демо-версию проекта](https://react-rsb.vercel.app/)

> ⚠️  Данный проект является исключительно учебной работой (Educational Clone), создан в целях комплексного изучения фронтенд-разработки, адаптивной верстки и интеграции с гео- и финансовыми сервисами. Проект не является коммерческим продуктом и не собирает персональные данные.

Проект представляет собой одностраничное приложение (SPA) интернет-банка, разработанную на базе React и JSS (CSS-in-JS). 

* **Авторство дизайна:** Визуальный интерфейс спроектирован в рамках дисциплины «UI/UX дизайн (Паттерны проектирования дизайна и исследование пользовательского опыта)» университета **Синергия**. Оригинальный дизайн-концепт детально разобран и предоставлен преподавателем курса, а затем дополнен в учебных целях для отработки навыков работы в Figma.
* **Авторство разработки:** Самостоятельная техническая реализация архитектуры, логики, стейт-менеджмента и фронтенд-части с нуля.

---

## 🛠 Стек технологий и архитектура
* **Frontend-библиотека:** React.js
* **Стилизация:** JSS (CSS-in-JS)
* **Сборщик проекта:** Vite
* **Маршрутизация и Сессия:** React Router Dom (механизм `createBrowserRouter`)
* **Работа с формами:** React Hook Form + встроенный контекстный провайдер FormProvider
* **Интеграции и API:** 
  * API Яндекс.Карт (модули `suggest`, `geocode`, `geolocation`).
  * API Центрального Банка РФ через скрипт `cbr-xml-daily.ru` (ежедневные официальные котировки валют).
  * API собственной разработки на .NET 9 Core ([DotnetRSB](https://github.com/VasinVladislav/DotnetRSB)) с интеграцией `Supabase (PostgreSQL)`.

Приложение спроектировано компонентно и разделено на 4 страницы и 9 ключевых функциональных блоков.

## 🗺️ Структура Маршрутов и Навигации

Приложение использует декларативную карту путей, разделенную на публичные и приватные контуры:

- ` / ` — Главный промо-лендинг (включает интерактивные кнопки оформления карт, меню табов и виджет входа в личный кабинет).
- `/register` `[Protected by RegistrationGuard]` — Анкета создания профиля. Доступна строго в том случае, если пользователь успешно подтвердил телефон на Шаге 1 регистрационной воронки.
- `/dashboard` `[Protected by ProtectedRoute]` — Главный экран личного кабинета (Мои карты, счета, транзакции).
- `/settings` `[Protected by ProtectedRoute]` — Настройки профиля, разделенные на блоки "Личные данные" (Read-only в целях безопасности) и формы смены пароля/Email.

## 📦 Детальный разбор компонентов

### 1. Header (Многоуровневая навигация)
Сложная навигационная панель, построенная по принципу строгой декомпозиции (разделена на подкомпоненты `LevelOne`, `LevelTwo`, `LevelThree`).

* **3-х уровневая архитектура меню:** Динамическое управление шторками и выпадающими списками.
* **Синхронизация гео-данных:** Инициализация стейта `selectedCity` происходит через утилиту `getSelectedCity()`. Хук `useEffect` подписывается на событие автоматического определения города от Яндекс.Карт через модуль `yandexCityDetected`. Выбор нового региона в хедере синхронизирует глобальное состояние и автоматически меняет центровку интерактивной карты ниже на странице.

### 2. PromoBlock (Главный баннер и авторизация)
Маркетинговый блок (Hero Section), совмещающий в себе паттерн привлечения внимания и точку входа в пользовательский интерфейс.

* **Двухколоночная структура (Split-screen):** Четкое визуальное разделение фокуса пользователя. Левая часть генерирует лиды (акцент на акцию «Кэшбек 10%»), правая — обеспечивает быстрый доступ в личный кабинет для действующих клиентов.

### 3. CatalogSection (Динамический каталог и Квиз-интеграция)
Интерактивная витрина банковских продуктов с гибким переключением категорий и встроенным геймифицированным элементом.

* **Гибридный стейт-менеджмент табов:** Реализована автоматическая ротация категорий («Личные финансы», «Молодежи», «Премиум» и др.). 
* **Умная остановка автоплея:** При ручном взаимодействии (клик пользователя по любому табу) таймер автоматически сбрасывается.

### 4. MapBlock (Интерактивная карта с геосервисами)
Сложный гео-компонент, реализующий автоматическое центрирование, поиск адресов и динамическую фильтрацию инфраструктуры.

* **Архитектурное разделение (Custom Hooks):** Вся императивная работа с инстансом карты, подпиской на события `onLoad` и инициализацией поискового саджеста (`suggest,geocode,geolocation`) изолирована в кастомный хук `useMapSuggest()`.
* **Автоматическое определение локации:** При первичном рендеринге приложение запрашивает геопозицию пользователя и центрирует карту на его координатах.
* **Умный поиск с автодополнением (Suggest API):** В инпут ввода адреса встроен механизм поисковых подсказок от Яндекса. При выборе адреса карта автоматически перемещает фокус.
* **Динамическая фильтрация:** Переключатель «Офисы / Банкоматы» перестраивает массив гео-меток на карте, изменяя их визуальный пресет (синие метки для отделений, красные — для банкоматов). Чекбоксы фильтров услуг в текущей версии являются декоративными.

### 5. Footer (Информационный подвал и курсы валют)
Заключительный информационный блок, воссоздающий структуру и юридические стандарты реального банковского интерфейса с интеграцией динамических данных регулятора.

* **Интеграция с API Центрального Банка РФ:** Актуальные котировки валют загружаются напрямую с серверов ЦБ РФ через интеграционный скрипт `cbr-xml-daily.ru`, подключенный в `index.html`. Данные инициализируют глобальный объект обмена `window.fx`.

### 6. AuthModal (Многошаговая OTP-авторизация и Token-Based Session)
Компонент интеллектуальной формы входа в интернет-банк, связанный с виджетом `LoginButton` в шапке.

* **Многошаговый интерфейс (Multi-step Form):** Процесс разделен на два изолированных подкомпонента (`StepOne` и `StepTwo`). Интерфейс сначала запрашивает телефон, верифицирует его на сервере .NET Core, и только потом плавно переключает пользователя на шаг ввода пароля. Если введённый номер телефона новый, клиента перенаправляют на страницу регистрации `(/register)`.

* **Автоматизация сетевого слоя (Axios Interceptors):** Архитектура входа полностью очищена от ручной отправки телефонов. При успешном логине сервер выдает уникальный GUID-токен сессии. Глобальный перехватчик Axios автоматически считывает его из локального хранилища и прикрепляет к каждому HTTP-запросу по стандарту `Authorization: Bearer <token>`.


### 7. Register (Страница регистрации)
Полноценная двухколоночная анкета создания личного профиля клиента
* **Автоматическое управление отчеством:** Реализован связанный стейт для чекбокса «У меня нет отчества». При его активации инпут отчества блокируется, очищается, а его обязательность в `React Hook Form` аннулируется.

* **Фильтрация ввода (Regex-фильтр):** На поля создания пароля установлено регулярное выражение `replace(/[^A-Za-z\d@$!%*?&_-]/g, "")` внутри события `onChange`. Фильтр блокирует ввод кириллицы на лету. Паттерн валидации проверяет строгость состава (минимум 8 символов, обязательное наличие латинских букв и цифр).
### 8. Dashboard (Личный кабинет)
Приватный центр управления финансами авторизованного пользователя, защищенный декоративным шлюзом ProtectedRoute на клиенте и авторизационным барьером на бэкенде. Личный кабинет не имеет функциональных элементов и служит в качестве визуального оформления.

### 9. Settings (Настройки профиля)
Интерфейс управления личным аккаунтом, спроектированный по безличному REST-принципу (сервер определяет автора запроса исключительно по присланному токену в Headers).

## 💻 Локальный запуск проекта

### 1. Установите зависимости проекта:

  ```bash
  npm install
  ```

### 2. Настройте переменные окружения:
В проекте реализовано автоматическое разделение контуров разработки и продакшена. Создайте в корне проекта два конфигурационных файла:

- **Для локальной разработки (`.env.development`):**
  Указывает прямой путь к запущенному .NET Core серверу:
  ```env
  VITE_API_URL=http://localhost:5000/api/
  ```

- **Для боевого сервера (`.env.production`):**
  Использует относительный путь для прокси-сервера (Amvera / Vercel / Nginx):
  ```env
  VITE_API_URL=/api/
  ```

### 3. Запустите локальный сервер разработки:
```bash
npm run dev
```
*Интерфейс откроется по адресу `http://localhost:5173.` Для корректной обработки авторизации, регистрации и смены паролей убедитесь, что на вашем компьютере параллельно запущен бэкенд-сервер .NET Core (`dotnet run`).*
